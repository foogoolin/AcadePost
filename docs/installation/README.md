# Installation

Guides destines aux admins qui veulent lancer AcadéPost depuis le depot GitHub.

- [demo-server-deploy.md](demo-server-deploy.md): installation Docker sur un serveur Linux simple.
- [demo-shared-infra-deploy.md](demo-shared-infra-deploy.md): installation sur une infra qui possede deja reverse proxy, PostgreSQL et reseaux Docker.

Le chemin actuel utilise des images GHCR preconstruites. Le serveur ne doit pas lancer de build local pour une installation ou mise a jour normale.
