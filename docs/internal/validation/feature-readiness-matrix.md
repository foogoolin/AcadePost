This matrix is controlled by the BYAN validation process. UI presence is not proof of functionality. A feature moves forward only when code evidence, API evidence, browser evidence, or client self-host evidence is recorded.

## Status Legend

- `UI_ONLY`: screen or copy exists, but no meaningful workflow is proven.
- `API_EXISTS`: endpoint or service exists, but no end-to-end proof yet.
- `BACKEND_WORKS`: backend behavior is verified with local/API checks.
- `E2E_VERIFIED`: browser/API workflow is verified on the deployed stack.
- `SELF_HOST_VERIFIED`: the same workflow is verified on a clean self-host install path.
- `CLIENT_READY`: repeatable, documented, and safe enough for a client demo or install.
- `BLOCKED`: missing credentials, external approval, code defect, or unsafe behavior blocks verification.

## First Hard Finding

Content Routing must not be sold as working routing today. It is currently a static guide/navigation page with platform suggestions and links. There is no discovered API route, persistence field, or DTO field that carries `video`, `short_text`, or `carousel` into post creation or scheduling.

Minimum implementation required before changing the status:

1. Add routing metadata to the post/domain model.
2. Add route/API support for creating a routed draft or scheduled post.
3. Connect the UI cards to an actual selection workflow.
4. Persist routing type and selected/recommended integrations.
5. Show the routed type in calendar/post details.
6. Expose routing metadata through the public API.

## Immediate Validation Queue

1. Public API collection: upload, create draft post, list/update/delete post, render template, create agent run, negative auth.
2. n8n smoke: import minimal workflow, test AcadePost webhook, test public agent-run headers and scopes.
3. Docker clean install: client-like fresh VPS path, then update and rollback.
4. Security pass: remove raw body logging, rate-limit review, API key rotation, agent secret rotation, upload and OAuth abuse cases.
5. Browser E2E: project switch, media upload, editor render, calendar draft/schedule, provider credential save/test.
